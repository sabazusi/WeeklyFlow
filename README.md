# WeeklyFlow

メニューバーからワンクリックで開く、Mac用の軽量タスクアプリです。アイコンの下にタイトルバーのないパネルを表示し、Inbox、実行リスト、完了履歴を管理します。今週完了したタスクを週報用にコピーできます。

## 動作環境

- macOS 14以降
- Xcode 16以降（ソースからビルドする場合）

## 起動方法

1. `WeeklyFlow.xcodeproj`をXcodeで開きます。
2. `WeeklyFlow`スキームを選択して実行します。
3. メニューバーのチェックマークをクリックするとパネルが前面に開き、実行リストの追加欄に入力位置が移ります。もう一度クリックすると閉じます。

署名が必要な場合は、Xcodeのターゲット設定で自分のTeamとBundle Identifierを指定してください。パネルを閉じてもアプリはメニューバーに残ります。終了するには左下の「終了」を押します。

## 使い方

- タイトルを入力して追加するとInboxに入ります。実行リスト画面から追加すると、直接実行リストに入ります。追加後は新しいタスクがある先頭までスクロールします。
- パネルを開くと実行リストの追加欄にフォーカスします。ショートカットで開き、文字を入力してEnterを押すだけで実行リストに追加できます。続けて次のタスクも入力できます。
- 入力欄ではCmd+A/C/V/X/ZとCtrl+A/C/V/X/Zを使えます。Shift+Zでやり直し、Ctrl+Yでもやり直しができます。
- Inboxの「実行リストへ」で整理します。丸いアイコンで完了・完了取り消しができます。
- タスクの「編集」で任意のURLを設定できます。`example.com`のように入力すると`https://`を補い、http/https以外のURLは保存できません。URLを設定したタスクは一覧のリンクアイコンからブラウザで開けます。
- Inboxと実行リストのタスクはドラッグで並べ替えられます。実行リストから「Inboxへ」で戻せます。
- 完了履歴は月曜始まりの週ごとに表示されます。各週の「コピー」で、その週だけの日時付き完了一覧をコピーできます。
- 「今週やったこと」は月曜0時から日曜23時59分までの完了を集計します。「コピー」で日時付きの一覧をクリップボードに入れます。
- 「設定」からログイン時の自動起動を切り替えられます。macOS側でログイン項目の許可待ちの場合は、その旨を表示します。
- 「設定」の「全アプリ共通のショートカット」で、修飾キー2つ以上と英数字を押すと登録できます。別のアプリを使用中でも、そのキーでパネルを開閉できます。Escで設定を中止し、「解除」で登録を消せます。
- 「Shiftを2回押して開閉」をオンにすると、同じ側のShiftキーだけを素早く2回押してパネルを開閉できます。間に文字キーなどを押した場合は開閉しません。ほかのアプリでも使うにはmacOSの「プライバシーとセキュリティ」→「アクセシビリティ」でWeeklyFlowの許可が必要です。許可後にWeeklyFlowへ戻ると監視を開始します。通常のキー操作は変更しません。

タスクデータはSwiftDataによってこのMacのユーザー領域に保存されます。クラウド同期、期限、通知はありません。GitHubに公開する際は、個人のタスクデータやビルド成果物を追加しないでください。

## テスト

Xcodeで`WeeklyFlow`スキームのTestを実行するか、次のコマンドを使用します。

```sh
xcodebuild -project WeeklyFlow.xcodeproj -scheme WeeklyFlow -destination 'platform=macOS' test
```
